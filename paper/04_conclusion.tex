\section{Conclusion}
\label{sec:conclusion}
The implementation connects MobileNetV2 conversion, optional pruning, TFLite inference, FastAPI serving, and Docker packaging. Its reference profile provides an illustrative comparison; it does not establish physical performance, accuracy preservation, or accelerator speedup.

An empirical submission requires a documented calibration and validation set, model and dataset hashes, raw timing and memory logs from named devices, synchronized power measurements, and a controlled container-overhead experiment. Pruning must be evaluated after training with the appropriate callbacks. The current live benchmark is a host diagnostic using synthetic inputs; it compares different backends and retains both models in one process, so it cannot isolate the effects of precision or model memory. These limitations define the next experimental steps for validating the deployment pipeline.
