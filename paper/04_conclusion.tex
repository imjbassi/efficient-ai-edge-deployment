\section{Conclusion}
\label{sec:conclusion}

This study turns an edge-deployment concept into a reproducible conversion, evaluation, and serving artifact. Full-integer quantization compressed MobileNetV2 by 3.50$\times$ and improved single-thread host inference by 1.32$\times$ while changing top-1 accuracy by less than one percentage point on the full Imagenette validation split. The result supports the engineering value of calibrated INT8 conversion under a controlled host protocol.

The next empirical step is deployment on named ARM edge devices using the same model hashes and inputs. That study should isolate native inference from HTTP and container overhead, measure process memory in separate runs, and collect synchronized wall-power and temperature traces. The present repository supplies the model artifacts, dataset checksum, raw timings, and service needed to conduct that extension.
