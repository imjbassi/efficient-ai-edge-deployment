\section{Introduction}
\label{sec:intro}
Running inference near the source of data can reduce network dependence, response time, and the need to transmit sensitive inputs. The same setting exposes constraints that are less visible in cloud deployment: limited memory, modest CPUs, heterogeneous accelerators, thermal budgets, and difficult software maintenance. A useful edge system must therefore treat model compression and packaging as a joint engineering problem.

Post-training quantization maps floating-point tensors to lower-precision representations and can reduce storage and arithmetic cost \cite{jacob2018quantization}. Pruning can remove low-contribution parameters, although the benefit depends on whether the target runtime exploits the resulting sparsity \cite{han2016deep,li2017pruning}. MobileNetV2 is a representative compact convolutional architecture for this setting \cite{sandler2018mobilenetv2}. TensorFlow Lite provides an integer-oriented deployment path for embedded inference \cite{tflite_integer}.

This work contributes an artifact-centered implementation that connects those model transformations to a FastAPI service and a resource-constrained Docker deployment. The repository includes source code, configuration, benchmark data, and a multi-file IEEEtran manuscript. Rather than claiming unverified hardware experiments, we make the provenance of the supplied numbers explicit. The reference profile is useful for exercising the reporting and deployment workflow, but it is not a substitute for a controlled experiment on named hardware.

The paper addresses three questions: (1) how should a compact model be converted and served at the edge, (2) which quantities can be reproduced directly from the repository, and (3) which claims require additional hardware, dataset, and measurement artifacts? Section~\ref{sec:methodology} describes the implementation. Section~\ref{sec:benchmarks} reports the reference profile and its limitations. Section~\ref{sec:conclusion} summarizes the resulting publication and reproducibility requirements.
