\section{Methodology}
\label{sec:methodology}

\subsection{Model conversion}

The source model is MobileNetV2 with ImageNet weights and a $224\times224\times3$ input. TensorFlow 2.15.1 exports the same SavedModel graph twice. The first conversion retains FP32 tensors. The second enables default optimization, restricts operators to the built-in INT8 set, and requests signed INT8 inputs and outputs. A representative dataset of 200 training images calibrates activation ranges. For scale $S$, zero point $Z$, and integer bounds $q_{\min}$ and $q_{\max}$, an input value $x$ is mapped as
\begin{equation}
q=\operatorname{clip}(\operatorname{round}(x/S)+Z,q_{\min},q_{\max}).
\end{equation}
Both conversion outputs are retained with SHA-256 hashes.

Pruning is outside the reported pipeline. No pruning accuracy or speed claim is made.

\subsection{Dataset and accuracy protocol}

Imagenette is a ten-class subset of ImageNet containing tench, English springer, cassette player, chain saw, church, French horn, garbage truck, gas pump, golf ball, and parachute \cite{imagenette}. The 160-pixel distribution contains 9,470 training and 3,925 validation images. Its archive is identified by SHA-256 digest \texttt{64d0c485...db02fe5}. Calibration images are selected from the training split with seed 20260914. All validation images are evaluated.

Each image is converted to RGB, resized so its shortest side is 256 pixels, center-cropped to $224\times224$, and scaled to $[-1,1]$. Predicted indices are compared with the corresponding ImageNet class indices. We report top-1 and top-5 accuracy and Wilson 95\% confidence intervals. The use of ImageNet-pretrained weights means this experiment evaluates conversion fidelity on an ImageNet subset; it is not an Imagenette training benchmark.

\subsection{Latency protocol}

Latency is measured with TensorFlow Lite's XNNPACK CPU delegate on an AMD Ryzen 5 7600 running Windows build 26100. One interpreter thread is used, oneDNN graph optimizations are disabled, and preprocessing is excluded. After 50 untimed warm-up invocations, 500 deterministically shuffled validation inputs are timed individually with a monotonic nanosecond clock. The paper reports mean, median, 90th percentile, standard deviation, and throughput computed as the reciprocal of mean latency.

\subsection{Serving and packaging}

The FastAPI service loads \texttt{models/mobilenet\_v2\_int8.tflite}, validates upload size and image decoding, applies the evaluation resize, crop, and scaling procedure, quantizes according to tensor metadata, serializes interpreter access with a lock, and exposes health and metadata endpoints. Missing models return HTTP 503. The container runs as a non-root user with CPU and memory ceilings. These controls define deployment behavior; they are not treated as Raspberry Pi, Jetson, power, or container-overhead measurements.
